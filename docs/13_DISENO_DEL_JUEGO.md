# Diseño del juego

## Estructura del mundo

El archipiélago permite ver destinos lejanos y controlar el streaming. Cada isla debe tener:

- una silueta reconocible;
- un punto alto;
- un elemento de navegación;
- una interacción sistémica;
- un secreto;
- una razón para volver.

## Bucle

```text
Observar
→ Elegir destino
→ Navegar
→ Explorar
→ Combatir o resolver
→ Conseguir capacidad
→ Abrir nueva ruta
→ Volver al mar
```

## Vertical slice

La primera isla jugable contiene:

- playa;
- pequeña aldea;
- torre escalable;
- bosque;
- campamento;
- cueva;
- santuario;
- miniboss;
- salto con planeador;
- trayecto de barco.

Duración: 30–45 minutos.

## Progresión

La progresión evita estadísticas excesivas. Se centra en:

- capacidades;
- herramientas;
- nuevas combinaciones;
- resistencia;
- espacio de inventario;
- conocimiento del mundo.

## Inventario VR

- Slots limitados.
- Acceso rápido físico.
- Mochila o cinturón opcional.
- Menús 2D flotantes sólo donde sea más cómodo.
- No obligar a realizar gestos agotadores repetidamente.

## Combate

El jugador puede:

- bloquear;
- desviar;
- atacar;
- disparar;
- usar entorno;
- retirarse;
- aprovechar altura.

Los enemigos deben comunicar ataques con animación y sonido claros.

## Santuarios

Pequeñas pruebas que combinan:

- física simple;
- movimiento;
- elementos;
- observación;
- destreza VR.

No deben depender de precisión milimétrica ni generar mareos.

## Identidad

La estética es cel-shaded, marítima y colorida, pero personajes, mundo, historia, música, símbolos y diseños serán originales.
