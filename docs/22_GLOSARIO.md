# Glosario

**ADR:** Architecture Decision Record.  
**Billboard:** plano que orienta una imagen hacia la cámara.  
**Culling:** descarte de objetos que no deben renderizarse.  
**Draw call:** orden de dibujo enviada al renderer.  
**FFR:** Fixed Foveated Rendering.  
**HLOD:** representación combinada de un conjunto lejano.  
**Impostor:** imagen o atlas que representa un objeto 3D desde una o varias vistas.  
**LOD:** Level of Detail.  
**Mod API:** contrato público para registrar y extender contenido.  
**MultiMesh:** instancing de muchas copias de una malla.  
**Namespace:** prefijo que evita colisiones de IDs.  
**OpenXR:** estándar abierto de APIs XR.  
**PCK:** paquete de recursos de Godot.  
**P95/P99:** percentiles de rendimiento.  
**Render scale:** escala interna de resolución.  
**Sector:** unidad espacial de streaming.  
**Vertical slice:** porción pequeña que representa la calidad final.
